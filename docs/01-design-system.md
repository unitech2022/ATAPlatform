## 2. الخط

- **IBM Plex Sans Arabic** (أوزان 400 / 500 / 600 / 700). النموذج يستخدم `font-black` أيضاً؛ نعتمد **700** كأقصى وزن فعلي.
- الاتجاه: RTL افتراضي للعربية، LTR للإنجليزية. الأرقام وحقول الهاتف/OTP تُعرض دائماً `dir="ltr"`.

| المستوى | الحجم | الوزن |
|---|---|---|
| Display | 36–48px | 700 |
| Title | 28–30px | 700 |
| Section | 18–20px | 700 |
| Body | 16px | 400/500، line-height 1.75 |
| Caption | 12–14px | 600/700 |
| Eyebrow | 14px | 700، لون `brand` |

## 3. الأشكال والمسافات

- نصف قطر الزوايا: بطاقات `24px` (rounded-3xl)، عناصر/أزرار `16px` (rounded-2xl)، صغيرة `12px` (rounded-xl)، حبوب `9999px`.
- ارتفاع الهيدر `80px`، أبيض بحد سفلي `line` و`shadow-soft`.
- حشو البطاقة 20–24px، بين البطاقات 12–24px.
- الزر الرئيسي: خلفية `ink`، نص أبيض 700، ارتفاع ~56px، `shadow-button`. المعطل: خلفية `line`.
- الزر الثانوي: حد `line` على أبيض، أو خلفية `brand` بنص أبيض (شحن المحفظة).
- Toggle: 48×28px، مفعّل `brand`، غير مفعّل `line`، مقبض أبيض 20px.
- الحقل المُركّز: حد 2px `brand` + `shadow-brand`.
- الأيقونات: SVG خطية `viewBox 24`، `stroke-width 1.8`، `round caps` — المجموعة: arrow, bell, car, check, chevron, clock, document, home, location, menu, pin, plus, phone, search, shield, upload, user, wallet.
- لوحة الأرقام (Keypad): شبكة 3 أعمدة، أزرار `cloud` مستديرة 16px، ارتفاع 52px، نص 20px 700، hover `brand-soft`، زر "حذف" نصي.
- حقل OTP: 4 خانات 56×56، حد 2px، المملوءة `brand` + `brand-soft`.

## 4. أنماط الشاشات

- **الترحيب/التسجيل**: خلفية `canvas` مع دائرتين مزخرفتين (`brand/10` أعلى اليمين، `ink/5` أسفل اليسار)، شعار ATA أعلى، زر "رجوع" حبة بيضاء.
- **الرئيسية للراكب**: خريطة تملأ الشاشة + لوحة (Bottom Sheet على الموبايل بارتفاع حتى 78% وزوايا علوية 32px / لوحة جانبية 432px على الشاشات الكبيرة).
- **شريط التنقل السفلي (موبايل)**: عائم داخل هوامش 16px، خلفية `ink`، زوايا 16px، العنصر النشط خلفية `brand`. عناصره: الرئيسية، رحلاتي، المحفظة، حسابي. يختفي في الشاشة الرئيسية (الخريطة).
- **بطاقات الإحصاء**: أيقونة في مربع `brand-soft` 44px، عنوان `muted`، رقم 30px 700.
- **البطاقة الداكنة**: خلفية `ink`، نص أبيض، شارة `white/10`، شريط تقدم `brand`.
- **قائمة الإعدادات**: صفوف بأيقونة 44px `cloud` + عنوان + وصف `muted` + chevron، فاصل `line`.
